# Contributing

Thanks for helping improve the SunLicense JavaScript SDK.

- **Bugs and ideas:** open an issue with the SDK version, what you expected and what happened.
- **Security issues:** don't open an issue; follow [SECURITY.md](SECURITY.md).
- **Pull requests:** keep them small and focused, add or update tests for the change, and make sure the test suite
  passes (`npm test`). CI runs the tests on every pull request, and a
  maintainer reviews every change before it is merged.
- **Releases** are tagged `vX.Y.Z` and described in the GitHub release notes.

By contributing you agree that your contribution is licensed under the repository's [MIT license](LICENSE).
