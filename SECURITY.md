# Security policy

## Supported versions

Security fixes go into the latest release of the `sunlicense` npm package. Please upgrade to the newest version before reporting.

| Version | Supported |
|---|---|
| Latest minor release (0.2.x) | Yes |
| Older releases | No |

## Reporting a vulnerability

Please **don't open a public issue** for a security problem.

Email **hello@sundevs.net** with "Security" in the subject, or use GitHub's private
[vulnerability reporting](../../security/advisories/new) for this repository. Include the SDK version, what you found,
steps to reproduce and the impact.

- We acknowledge every report within **3 business days** and keep you updated.
- We aim to fix confirmed issues within 72 hours (critical), 14 days (high) or 30 days (medium).
- Once a fix is released we publish a GitHub security advisory and, if you wish, credit you.

Reports are handled under SunLicense's [Vulnerability disclosure policy](https://docs.sunlicense.com/legal/vulnerability-disclosure),
which includes safe harbor for good-faith research. Issues in the SunLicense service itself (sunlicense.com, the API, the
dashboard) are welcome through the same channel.
